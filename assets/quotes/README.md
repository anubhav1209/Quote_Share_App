# Quote Template Images

## Required Images

Please add 3 quote template images to this folder with the following names:
- `quote1.jpg` - Inspirational/Motivational quote
- `quote2.jpg` - Business/Professional quote  
- `quote3.jpg` - General wisdom quote

## Image Specifications
- **Format:** JPG or PNG
- **Resolution:** 1080x1920 (portrait, 9:16 aspect ratio)
- **Design Guidelines:**
  - Use vibrant gradient backgrounds
  - Include inspirational text in the center
  - Leave space at top-left for date badge (100x40px area)
  - Leave space at bottom-left for user photo (80x80px circular area)
  - Ensure good contrast for text overlay

## Temporary Placeholders

For now, the app will use colored placeholders. Replace these with actual quote images before final build.
