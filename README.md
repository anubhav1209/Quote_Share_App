## Features

### Core Functionality
- 📱 **Phone Authentication** - Secure OTP flow
- 🎨 **Quote Personalization** - Add your name & photo to templates
- 🔄 **Quote Carousel** - Browse through beautiful templates
- 📸 **Photo Upload** - Add photos from camera or gallery
- ✨ **Suvichar Branding** - Custom headers and UI
- 🔒 **Secure Ownership** - Built-in verification system

### Screens
1. **Welcome Screen** - Phone input with "+91"
2. **OTP Verification** - 60s timer + resend
3. **Purpose Selection** - Personal or Business use
4. **Profile Setup** - Custom profile creation
5. **Main Screen** - Quote sharing dashboard
6. **Profile Screen** - Account management with **Logout** & **Verification**

## Technical Stack

- **Framework**: Flutter
- **Language**: Dart
- **Architecture**: Provider (State Management)
- **Backend**: Mock Auth (Firebase Ready)
- **Platform**: Android

## Setup & Run

   ```bash

   ```

