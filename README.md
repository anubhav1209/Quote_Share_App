# Suvichar

A premium Flutter application for creating, customizing, and sharing beautiful daily quotes and status updates.

## ✨ Features

*   **Authentication**: Secure mobile number login with OTP verification.
*   **Quote Gallery**: Browse a curated collection of high-quality quote templates.
*   **Personalization**: Automatically overlay your name and profile photo on any quote.
*   **Customization**: Edit text, change backgrounds, and adjust styling before sharing.
*   **Save & Share**: Download quotes directly to your gallery or share them instantly on social media.
*   **Profile Manager**: Manage your personal or business details and view your download history.

## 🛠️ Tech Stack

*   **Framework**: Flutter (Dart)
*   **State Management**: Provider
*   **Backend**: Firebase (Firestore)
*   **Platform**: Android
*   **Architecture**: MVVM-inspired

## 🚀 Getting Started

### Prerequisites
*   [Flutter SDK](https://flutter.dev/docs/get-started/install) installed.
*   Android Studio or VS Code configured.

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/Start-Tworks/Suvichar-App.git
    cd Suvichar-App
    ```

2.  **Install dependencies**
    ```bash
    flutter pub get
    ```

3.  **Run the app**
    ```bash
    flutter run
    ```
